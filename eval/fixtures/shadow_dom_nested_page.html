Borealis Kit gallery

SENTINEL-NEST-TEXT the gallery ships one web component per card. Each card opens its own shadow root, and the tab strip inside it opens a second root, so developers can read the markup once and copy it into a page. The pattern follows the web.dev shadow DOM guide.
